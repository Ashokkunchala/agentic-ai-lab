# Agentic AI Lab Roadmap

## 00 Foundations
LLM vs chatbot vs agent; goals, state, tools, observations, policy and verification.

## 01 First Agent
Build the smallest deterministic goal-driven loop.

## 02 Tool Calling
Learn typed inputs, registries, validation and tool errors.

## 03 Agent Loop
Observe → decide → act → verify with bounded steps.

## 04 Memory
Separate immediate context, working memory and persistent memory.

## 05 Planning
Decompose goals into dependency-aware steps.

## 06 RAG
Treat retrieval as a tool and learn grounding.

## 07 MCP
Learn client, server, tools/resources and host-side policy.

## 08 Multi-Agent
Study delegation and coordination cost.

## 09 Coding Agent
Repository inspection, controlled edits, tests and verification.

## 10 DevOps Agent
AWS, Docker, Terraform, Kubernetes and CI/CD.

## 11 Autonomous Agent
Budgets, approvals, retries, rollback and audit logs.

## 12 Production Architecture
Security, observability, evaluation, state and model routing.

## 13 Cloudflare
Workers/Queues/Durable Objects as a control plane with privileged execution isolated.
